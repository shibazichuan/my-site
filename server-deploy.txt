## 一、服务器部署（在阿里云终端执行）

cd /opt/my-site && git pull origin master && docker compose -f docker-compose.yml -f deploy/docker-compose.prod.yml up -d --build && docker exec my-site-backend-1 alembic upgrade head

---

## 二、Docker 镜像加速（解决 --build 被墙）

# 1. 获取阿里云镜像加速地址（免费）
#    登录 https://cr.console.aliyun.com → 镜像工具 → 镜像加速器
#    复制你的专属加速地址，例如:
#    https://xxxx.mirror.aliyuncs.com

# 2. 配置 Docker daemon
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": ["https://xxxx.mirror.aliyuncs.com"]
}
EOF

# 3. 重启 Docker
systemctl restart docker

## 六、GitHub Actions CI/CD 配置

# 需要把服务器 SSH 私钥加到 GitHub Secrets:
# 1. GitHub 仓库 → Settings → Secrets and variables → Actions
# 2. 添加三个 Secret:
#    SSH_HOST: 121.40.140.52
#    SSH_USER: root
#    SSH_KEY:  <服务器 SSH 私钥内容（~/.ssh/id_ed25519）>

# 3. 在服务器上生成 SSH 密钥（如果没有）:
#    ssh-keygen -t ed25519 -f ~/.ssh/github-actions -N ""
#    cat ~/.ssh/github-actions.pub >> ~/.ssh/authorized_keys
#    cat ~/.ssh/github-actions    # 这个内容复制到 GitHub Secret SSH_KEY

# 配置完成后，每次 git push 到 master 都会自动部署
