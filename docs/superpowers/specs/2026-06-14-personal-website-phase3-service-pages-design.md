# 个人网站 - 阶段三·第二部分：服务页面 设计文档

> **日期**: 2026-06-14
> **状态**: 已确认
> **概述**: 技术服务展示页面（外包开发、技术教学、DevOps、技术咨询）+ 悬浮客服

---

## 1. 范围

| 模块 | 内容 |
|------|------|
| 📄 服务页面 | Tab 切换四类服务，含功能清单、定价、CTA |
| 💬 悬浮客服 | 右下角气泡 → 展开聊天窗口（复用已有 AI Chat） |
| 🧭 导航 | Navbar 新增 "服务" 入口 |

### 不做

- 项目案例展示
- 后端存储（纯前端页面，客服复用已有 chat API）
- 独立后台管理

---

## 2. 路由

| 路由 | Tab | 说明 |
|------|-----|------|
| `/services` | 外包开发 (默认) | Web 应用、小程序、API、管理后台 |
| `/services/dev` | 外包开发 | 同上 |
| `/services/teaching` | 技术教学 | 1v1 辅导、面试准备 |
| `/services/devops` | DevOps | 部署、CI/CD、云迁移 |
| `/services/consulting` | 技术咨询 | 架构评审、性能优化 |

## 3. 各 Tab 内容

### 3.1 外包开发

- **简介**: 全栈开发经验，从需求分析到上线交付
- **功能**: Web 应用 · 微信小程序 · RESTful API · 管理后台 · 数据库设计
- **技术栈**: React / Vue / FastAPI / Node.js / PostgreSQL / Docker
- **价格**: ¥5,000 起（按项目复杂度评估）
- **交付**: 2-8 周

### 3.2 技术教学

- **简介**: 1v1 个性化辅导，从入门到就业
- **方向**: Python 后端 · React 前端 · 面试辅导 · 项目实战
- **价格**: ¥300/小时

### 3.3 DevOps

- **简介**: 让你的应用稳定、安全、可扩展
- **功能**: Docker 容器化 · CI/CD 流水线 · 云服务器部署 · 监控告警 · 数据库优化
- **价格**: 联系报价

### 3.4 技术咨询

- **简介**: 帮你做对技术决策，少走弯路
- **功能**: 架构评审 · 性能优化 · 技术选型 · 代码审查 · 安全评估
- **价格**: 联系报价

## 4. 悬浮客服

- 右下角固定 💬 气泡按钮
- 点击展开内嵌聊天窗口（复用 `ChatMain` 组件）
- 未登录 → 提示 "请先登录使用在线客服"
- 已登录 → 直接进入对话，系统提示词预设为咨询服务
- 悬浮窗尺寸：380×520px，可最小化
